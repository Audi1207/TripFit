
# TripFit ✈️

**Smart Travel Recommendation Application for Exploring Indonesia**

TripFit is a travel recommendation application designed to help users discover tourism destinations in Indonesia based on their interests, travel duration, and available budget.

The application uses the **K-Nearest Neighbors (KNN)** algorithm to provide personalized destination recommendations by considering user preferences and budget suitability.

## 🎯 Project Objectives

- Help users discover tourism destinations in Indonesia.
- Provide recommendations based on travel preferences.
- Consider travel duration and budget constraints.
- Make travel planning easier and more personalized.

## ✨ Planned Features

- User registration and login.
- Travel preference selection.
- Destination recommendations using KNN.
- Budget-based destination filtering.
- Travel duration consideration.
- Destination information and details.

## 🛠️ Technology Stack

| Component | Technology |
|---|---|
| Frontend | Flutter |
| Backend | Laravel REST API |
| Database | MySQL |
